# Reprise downloads

Public release downloads for optional Reprise tools. Reprise source development remains separate.

## Music Sketch Tools

Music Sketch Tools provides optional audio analysis for agent-assisted, editable song sketches. It installs separately from Reprise and includes its own Python runtime, audio tools and native project helpers. Saved sketches play without the analysis tools installed.

No tools release is available yet. Packages will appear under [Releases](https://github.com/cengebretson/reprise-downloads/releases) after platform verification and publisher signing are complete.

When releases are available, Reprise’s **Settings → Agent integrations…** card can show download sizes and offer optional installation. Opening Settings or installing an agent skill does not download the analysis runtime or models. Removing tools preserves songs, source audio and cached models.

Each versioned release will include platform archives, `catalog.json` with SHA-256 checksums, and verification evidence. Models download separately from their upstream source. Third-party notices ship with each package.
